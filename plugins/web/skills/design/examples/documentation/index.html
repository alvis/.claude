Tutorial / Getting started

Run your first job

Follow one local, illustrative flow from a job definition to an expected sample result.

Before you begin
This fictional tutorial assumes a JavaScript project and a sample Relay token. The commands do not connect to a real service.

  1. Add the sample client

    In a real product, verify the package name and runtime from authoritative documentation.

    Shell · illustrative 
    npm install @fictional/relay

  2. Define a job

    Name the work and keep the input explicit. This shape exists only for the example.

    JavaScript · illustrative 
    const job = relay.job({ name: "sample-report", run: async (input) => input });

  3. Inspect the expected result

    A successful sample returns a local object. It does not enqueue or execute remote work.

Explanation / Reliability

Understand retries

A conceptual guide to distinguishing a transient interruption from invalid input.

Choose the retry boundary

Retry only work that can safely repeat. Record an idempotency key before a side effect and keep an attempt’s outcome visible.

Explain the outcome

An error should name what failed, why the system believes it failed, and whether retrying is useful. This page defines no real service behavior.
